# Data policy

Synthetic data only, everywhere an agent works: code, fixtures, golden packets, tests, prompts, logs, screenshots, chat. Never enter, paste, fetch or generate anything resembling a real person's health data. Synthetic names must be obviously fake (`ZZTEST, Patient`; `ZZTEST, Referral`), MRNs and dates of birth must be clearly synthetic, and every golden packet carries its canary name and MRN so the no-PHI-in-logs check can find leaks. Real de-identified packets exist only in the BAA-covered evaluation environment, never on developer machines, in CI, in this repo, or anywhere a gateway such as OmniRoute can reach. No real credentials, keys, AWS account ids, bucket names or hostnames in any file; placeholders only (`<ACCOUNT_ID>`, `example.invalid`). Never read `.env` files. Product AI calls go to AWS Bedrock only, with a pinned model id; no other AI endpoint, gateway or proxy in any `@codex-health` package, env var or config.
